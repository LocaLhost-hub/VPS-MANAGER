

# 🛡️ VPS MANAGER v3.0

**VPS Manager** — это мощный Bash-скрипт для автоматической настройки **WireGuard VPN**, организации защищенных туннелей, управления портами и обеспечения безопасности вашего сервера.

Идеально подходит для создания **собственного VPN**, доступа к домашним сервисам из интернета («белый IP» для дома) и удаленного управления сервером.



##  Быстрая установка

Подключитесь к вашему VPS по SSH и выполните команду:

```bash
curl -sL https://raw.githubusercontent.com/LocaLhost-hub/VPS-MANAGER/main/bench.sh -o bench.sh && chmod +x bench.sh && sudo ./bench.sh

```

*После установки меню открывается командой:* **`vps`**

##  Основные возможности

* **⚡ WireGuard VPN:** Автоматическая установка, генерация ключей и QR-кодов.
* **🏠 Проброс портов (Port Forwarding):** Прокидывайте порты с публичного IP сервера на устройства в домашней сети (за NAT).
* **🛡️ Безопасность:**
* **GeoIP:** Блокировка всех входящих соединений, кроме разрешенных стран (WhiteList).
* **SSH Hardening:** Смена порта, вход только по ключам, Fail2Ban.
* **Anti-DDoS:** Базовая защита от флуда.


* **🏎️ Управление скоростью:** Шейпинг трафика (Limiter) для каждого клиента отдельно.
* **🤖 Telegram Бот:** Полноценное управление сервером через чат.
* **🌐 Web-Terminal:** Доступ к консоли сервера прямо из браузера.

**Возможности  Telegram Бот:**

* `📊 Инфраструктура`: Показывает IP, статус служб.
* `👥 Клиенты`: Список пользователей, их IP и лимиты скорости.
* `➕ Создать Клиента`: Создает конфиг и присылает файл `.conf` в чат.
* `🛡 Безопасность`: Вкл/Выкл SSH по паролю, управление GeoIP.
* `🔌 Добавить порт`: Открытие и переадрисация портов.

##  Инструкции по использованию

### 1.  Проброс портов

Скрипт позволяет использовать VPS как «шлюз» для доступа к вашим домашним сервисам (Home Assistant, RDP, камеры, NAS), даже если у вас дома "серый" IP.

1. При первоначальной настройке скрипт создает клиента с именем **Router**.
2. Скачайте конфиг `/root/wg_clients/Router.conf` (через SFTP или QR в меню).
3. Настройте этот конфиг на домашнем роутере (Keenetic, Mikrotik, OpenWRT) или сервере,откройте порты для WG подключения .
4. **Проброс порта:**
* В меню `vps` выберите **пункт 3 (Добавить порт)**.
* Введите порт (например, `8123` для Home Assistant).
* Выберите клиента **Router**.



### 2.  WEB-доступ к терминалу (Web UI)

Вы можете управлять сервером через браузер, даже если под рукой нет SSH-клиента. В меню выберите **пункт 8 (Тех. обслуживание) -> 8 (Web-Панель)**.

Доступно два режима:

####  Режим LOCAL (Безопасный)

Панель запускается на `127.0.0.1`. Доступ к ней возможен только через SSH-туннель. Это самый безопасный способ.

1. Запустите панель в режиме **Local**.
2. В терминале выполните команду:

```bash
ssh -L 17681:127.0.0.1:17681 root@IP_ВАШЕГО_VPS

```


3. Откройте в браузере: `http://127.0.0.1:17681`

####  Режим PUBLIC (Публичный + SSL)

Панель доступна из интернета по HTTPS.

1. В меню Web-панели выберите **Настроить SSL**.
2. Получите сертификат на IP или Домен (автоматически через Let's Encrypt/ZeroSSL).
3. Запустите панель в режиме **Public**.
4. Заходите по ссылке: `https://IP_ВАШЕГО_VPS:17681` (потребуется логин/пароль, заданный при старте).


### 3.  Настройка Telegram Бота

Управляйте сервером с телефона. Бот умеет создавать клиентов, присылать конфиги, банить IP и уведомлять о падении VPN.

1. Создайте бота в Telegram через **@BotFather** и получите `TOKEN`.
2. Узнайте свой цифровой ID через **@userinfobot** (это `ADMIN_ID`).
3. В меню скрипта выберите **пункт 9 (Telegram Бот)** -> **Установить**.
4. Введите Токен и ID.

### Настройка Anti-DDoS


Скрипт включает встроенную защиту от брутфорса (подбора паролей) и флуда (DoS-атак) для проброшенных портов. Это реализуется через модуль ядра xt_recent, который считает количество новых соединений с одного IP-адреса за определенное время.

Как это работает:
При добавлении нового порта (пункт меню 3), скрипт спрашивает режим защиты:

Стандарт (Recommended):

Лимит: 5 новых подключений за 60 секунд.

Для чего: Идеально для RDP, SSH, админок. Если злоумышленник попытается подобрать пароль, его IP будет заблокирован на уровне ядра.

Строго (Paranoid):

Лимит: 10 подключений за 24 часа (86400 сек).

Для чего: Для личных сервисов, куда вы заходите редко. Практически исключает любой брутфорс.

Выкл (Off):

Лимит: Отсутствует.

Для чего: Для публичных веб-сайтов, игровых серверов или VPN-шлюзов, где много легитимных подключений.

Выполните это в консоли:

```bash
sed -i 's/H=5; S=60/H=3; S=60/' bench.sh

```

### Что делает эта команда:

1. **Ищет** в файле текст `H=5; S=60` (это ваши старые настройки: 5 попыток за 60 сек).
2. **Заменяет** его на `H=3; S=60` (3 попытки за 60 сек).
3. **Сохраняет** изменения в файле.

Теперь при выборе режима **"Стандарт"** защита будет срабатывать быстрее.

---

Если вы хотите изменить и **"Строгий"** режим (сделать, например, 5 попыток за час вместо 10 за сутки), используйте эту команду:

```bash
sed -i 's/H=10; S=86400/H=5; S=3600/' bench.sh

```
Доступ к локальной домашней сети (Site-to-Site)
Если вы хотите через VPN попадать на домашние устройства (принтеры, NAS, серверы) по их локальным IP например 192.168.1.X.


```bash
# Замените 192.168.1.0/24 на вашу подсеть
SUBNET="192.168.1.0/24"

# Применяем настройку и перезагружаем
sed -i "/# Client: Router/,/AllowedIPs/ s|AllowedIPs = .*|&, $SUBNET|" /etc/wireguard/wg0.conf && systemctl restart wg-quick@wg0

```

**Как проверить, что сработало?**

```bash
wg show wg0 allowed-ips | grep "Router"
# Должно показать: 10.252.1.2/32, 192.168.1.0/24

```

**⚠️ Важно:**
На домашнем роутере/клиенте должен быть включен **IP Forwarding** и разрешен трафик из VPN в LAN.


##  Структура файлов

| Описание | Путь |
| --- | --- |
| **Основной конфиг WireGuard** | `/etc/wireguard/wg0.conf` |
| **Скрипт маршрутизации и правил** | `/etc/wireguard/up.sh` |
| **Конфиги клиентов (файлы)** | `/root/wg_clients/` |
| **SSH Ключи (публичные/приватные)** | `/etc/wireguard/ssh_key/` |
| **Белые списки GeoIP** | `/etc/ipset/whitelist.conf` |
| **Логи бота** | `journalctl -u tgbot -f` |
